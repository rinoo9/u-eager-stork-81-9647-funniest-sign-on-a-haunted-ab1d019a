Funniest Sign on a Haunted Server Room Door — a make.fun bounty entry.

The entry is one line, the sign taped to the door of a haunted server room:

> NOTICE: This room is haunted by the engineer who said 'just one more deploy on Friday'.

## Run it

```sh
python3 main.py
```

`main.py` writes the sign, deterministically, to `/output/entry.txt`
(87 characters, inside the 1–120 character gate). Run it twice and the
output is byte-identical.
